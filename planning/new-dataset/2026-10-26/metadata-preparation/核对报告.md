## 细胞 ID 与 GEO 映射

`coldata` 的 nrows=1920；顶层 rownames 是 NULL（R 序列化 NULL 标记），不能把其默认行号当作细胞 ID。`cell.type`、`diffusion`、`FACS` 三个嵌套矩阵各自带有显式细胞 ID，均有 1920 个唯一、非空 ID，且与重新获取的 GEO counts 表头逐项同序一致。

GEO SOFT 含 3840 条唯一样本记录。1920 条名称直接匹配矩阵 ID；另 1920 条名称含 `_Rep_`。仅按名称去掉 `_Rep_` 后，得到 1920 对候选对应关系，每个矩阵 ID 恰有一条直接 GSM 记录与一条 Rep 名称候选记录。直接匹配组包括 HSPC 852、LT-HSC 216、Prog 852。完整 GSM、BioSample、SRA 来源记录见 `metadata-audit/geo_sample_records.tsv`，逐细胞对应见 `cell_id_mapping.tsv`。

这是可复核的名称对应，**不证明 Rep 是独立细胞、生物学重复、技术重复或同一细胞重测**。不要合并 count、增加细胞数或将这些候选关系用于重复统计。三个名称前缀代表来源分选群候选，不等于细胞类型终态标签或 donor/batch ID。

## cell.type：23 列是成员标记，而非 23 个互斥类别

该字段是 1920×23 的稀疏矩阵，值仅 0/1，没有数值缺失。0 表示该标记未置位，不能一律解释为“已知其他类型”。136 行的全部 23 标记均为 0，意味着可用类型信息未分配。

| 层级/标记 | 类别及阳性数 |
|---|---|
| broad 六类 | LTHSC 323；LMPP 280；MPP 368；CMP 328；MEP 362；GMP 123 |
| fine 六类（原表无后缀） | LTHSC 323；LMPP 211；MPP 259；CMP 227；MEP 232；GMP 56 |
| broad 的 MPP 子类 | MPP1 68；MPP2 28；MPP3 162；STHSC 110 |
| fine 的 MPP 子类 | MPP1 29；MPP2 12；MPP3 66；STHSC 40 |
| 独立标记 | ESLAM 42；HSC1 126；Projected 183 |

broad 六类覆盖 1784 个细胞，类间没有多重归属；136 个未分配。fine 六类覆盖 1308 个，类间没有多重归属；612 个未分配。所有 fine 阳性均包含于对应 broad。broad MPP 的四个子类互斥且完整覆盖其 368 个父类细胞；fine MPP 子类互斥，仅覆盖父类 259 个中的 147 个，另 112 个无该子类分配。ESLAM/HSC1/Projected 应保留为独立标记，不能追加成平级唯一标签。

常用术语解释：LTHSC 为长期造血干细胞，STHSC 为短期造血干细胞，MPP 为多能祖细胞，LMPP 为淋巴倾向多能祖细胞，CMP 为共同髓系祖细胞，MEP 为巨核/红系祖细胞，GMP 为粒/单核巨噬系祖细胞。这些是免疫表型/分选门语义，不是已验证的功能命运真值。MPP1/2/3、ESLAM、HSC1 的精确抗体组合和门阈值仍须作者原始定义支持，不按名称补定义。Projected 目前只可解释为来源表中的该项标记；不能据此判定低质量、重复或自动排除。

较新 scRNAseq 整理代码也明确按 broad、fine、各自 MPP 子类和独立标记拆分，支持上述层级解释；它不是本轮更换数据版本的理由。

## diffusion 与 FACS

diffusion 为 DC1/DC2/DC3 三个作者提供的 diffusion map 坐标，是派生表示，不是实验批次、时间点或独立验证真值。421 行三个分量全缺失，1499 行完整，没有部分缺失或无穷值。本轮仅核查字段及缺失，没有重新计算或分析坐标几何。

FACS 为十列索引分选相关测量；430 行十列全缺失，1490 行完整，没有部分缺失或无穷值。

| 原始列名 | 可安全解释的字段含义 |
|---|---|
| FSC.H | 前向散射脉冲高度，细胞散射信号，不能当作表面蛋白表达 |
| CD34 | CD34 测量 |
| CD16 | CD16 标签测量；是否使用 CD16/32 联合抗体及克隆须核实 |
| c.Kit | c-Kit/CD117 测量 |
| EPCR | EPCR/CD201 测量 |
| Flk2 | Flk2/Flt3/CD135 测量 |
| CD150 | CD150/SLAMF1 测量 |
| CD48 | CD48 测量 |
| Lin | lineage 抗体混合通道；具体组成须核实 |
| Sca1 | Sca-1 测量；具体抗体及转换须核实 |

上表是通用标记名称解释；不声称作者的抗体克隆、荧光补偿、量纲、变换、阴阳阈值或重建门控均已核实。特别是不把这些数值当 RNA 表达或自行阈值化生成类型标签。

183 个 Projected 阳性中有 91 个缺失 diffusion、91 个缺失 FACS；非 Projected 中分别还有 330 和 339 个缺失。故 Projected 与缺失不能相互替代。逐细胞缺失及未分配标志见 `cell_metadata_flags.tsv`。
