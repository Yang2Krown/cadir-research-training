# 新数据与公平基线阶段：启动和验收规则

制定日期：2026-10-26（Asia/Shanghai），在查看新数据评价结果之前固定。本文先约束准备工作，不代表新数据已选定、阶段已放行或实验已运行。首阶段须有独立R3复核及主控结论后，才启动依赖它的正式新实验。

## 数据来源和新增性

1. 先清点原论文正文、补充材料与固定作者脚本所用数据，记录实际查阅范围及别名。不能只因某个文件名未被搜索到就宣称原论文未使用。
2. 核查两个公开候选，优先完整对象约1000—5000个细胞、有表达计数和有来源的参考标签、资源适合2核/8GiB且无需付费/申请。记录研究DOI、官方入口、数据版本/登录号、许可或使用条件、矩阵和标签的获得方式、体积及访问验证结果。
3. 换预处理或从原论文数据再切子集不构成新数据；来自不同研究的子集也须清楚标记筛选规则和原始规模，不能把子集冒称独立研究。确未使用的结论须有足够来源覆盖。
4. 数据审计记录对象、ID、矩阵方向、counts/logcounts、已有归一化、样本/供者、标签来源和缺失；不随意删双细胞或凑细胞数。取得数据后生成SHA256，原始字节只读、Git之外保存。

## 研究设计与冻结

科学问题为CAdir在新组织或细胞类型场景中的聚类效果和结果可解释性，不预设优于基线。先选一种合理基线，说明其正常流程；共同数据/QC/特征来源和资源预算保持公平，特有的降维/距离约定明确披露，不通过不合适配置使基线失效。

由Sol High在正式评价前提交完整配置：输入版本和筛选、预处理、特征、CA/PCA维度、CAdir/基线参数、固定种子列表、评价和缺失标签策略、资源测量范围、文件命名与失败处理。参考标签不用于设簇数、参数、后处理或筛选表现较好的运行。必要的标签可靠性审计与聚类配置决策分开记录。

参数和种子不能在见到ARI/NMI后按结果修改。确有实现错误需修复，保留原失败与配置，解释改变原因并重新固定版本；不把排错变成追分。

## CA基底与基因排名的已知限定

R3表明相同几何的CA符号选择可影响当前上游正正交限随机阈值及基因全排名。每次运行保存实际CA对象/基底、RNG、alpha、排序函数来源及全排名，分清分配、几何与排名。不据同种子直接宣称任意CA基底排名相同，不把单次排名作为独立生物学真值。

保持复现算法时不静默加入CA符号规范化或新随机采样；若研究需要基底无关排名，须在评价前另立方法变体、固定规则和独立评审，保留原算法对照。不利用参考标签选择符号约定。

## 评价、资源与独立验收

- 按原始细胞ID对齐可靠参考标签，明确ARI公式、NMI归一化（与当前案例一致时用MI/max熵）、评价/排除样本数、簇数量。不能把预测注释作真值。
- 保存全部预设种子及不利结果，区分同种子复跑和多种子稳健性；准确率、聚类分配和基因解释分别报告，不以单数据集证明普遍优势。
- 计时和内存注明实际硬件、进程范围、开始/结束点及安装/下载是否排除；方法间范围一致，不将一次工程诊断冒称性能基准。
- 正式实验前由独立Sol High检查数据新增性、标签/QC、算法调用和冻结设计；存在关键来源或设计缺口先修复复验。正式结果固定提交后再独立重算指标、查图、核对失败与预设配置，必要时隔离复跑。
- 新阶段报告、应用文稿和答辩主要结论以通过评审的证据为准；严格原论文复现仍另有marker/filtered输入及作者依赖等价性门槛。
