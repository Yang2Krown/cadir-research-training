## 任务正文

请使用当前已发布的 CAdir 云端环境，完成一个真实数据案例的最小复现。分两步执行：先验证快照恢复，再核对数据并运行；遇到明确阻塞时保留日志并报告。

1. 先核查当前任务的 CPU/内存/磁盘配额与可用空间，读取 `/workspace/.cadir-setup/START_SKILL.md` 与 `SOFTWARE.md`。这是新设置的 Docker 版环境，不使用旧环境的 `/workspace/cadir-env/activate.sh`。通过 `/workspace/.cadir-setup/run-r.sh` 运行 R，确认 R4.4.1、Bioconductor3.19及八个核心包。运行 `/workspace/.cadir-setup/run-r.sh Rscript /setup/smoke-test.R`，验证新任务中的快照、Docker 镜像及私有包目录能否正常恢复；若缺少镜像，先按已保存的安装说明重建，并记录耗时和空间。已成功部分直接复用，不擅自更换版本。
2. 找到本次附加的 `tabula_muris_limb_preproc.rds`。文件大小应为 43383527 字节，SHA256 应为 `af643523ccdf49e4931b5a0f8c53e67ba7fb24fbabb2fed7edfecf3b55c51f8b`，先校验再用 readRDS 读取。当前启动器只把研究仓库映射到容器 `/repo`，因此将已校验的数据复制到仓库内专门的数据目录，并加入本地 Git 排除，避免大数据入库；R 代码使用实际容器路径读取。不得假定本机 /Volumes 共享盘在云端可读。不要下载全量课程数据。
3. 先记录对象类型、结构、assay、细胞数、基因数、基因ID、元数据与参考标签字段，判断已做哪些预处理。如果找不到可靠标签就明确说明，不能用本次聚类输出充当参考标签。文件名不能证明对象内容；不要重复归一化已处理数据。
4. 核对论文第23页及作者复现脚本，优先查找该数据文件对应的实际案例与预处理。作者算法库 https://github.com/VingronLab/CAdir，论文复现库 https://github.com/VingronLab/CAdir_results。优先利用当前环境中保留的固定来源，记录实际所用提交；若需补充复现脚本，可仅获取必要文本，避免重新克隆附带数据的大仓库。
5. 论文 Limb Muscle 案例的目标配置为：1882个细胞、6000个高变基因、30个CA维度、初始k=8、角度阈值55度，使用 CellMarker2.0 注释。先核对当前对象与作者脚本是否对应，再按实际可支持的步骤运行。参考标签只用于事后评价，不作为聚类输入；固定并记录随机种子、实际参数和版本。
6. 优先交付从读入对象到 CA、CAdir、Association Plot、聚类与共聚类基因结果表的可重复流程。有可靠参考标签时再计算 ARI/NMI。自动细胞类型注释如需额外资源，明确来源和缺口，可作为单独步骤，不因此伪造已完成的注释或论文一致性。
7. 记录每个主要阶段的实际耗时、峰值内存、维度及失败日志，保留所有真实输出。若资源不足，报告触发错误、当前限制和最低需求，再建议是否租服务器，不自动购买资源。
8. 在研究仓库的独立分支整理自己的运行脚本、说明和结果索引；大数据、密钥、R运行库与安装缓存留在 Git 之外。保留上游来源和许可证。完成后报告复跑命令、修改文件、哪些步骤完成/未完成，以及与论文配置或环境版本的差异。
