# C04 一手来源覆盖记录

状态：**部分证据已取得，须独立科学评审裁定；C04 未完全关闭。** 本包只整理 Nestorowa / GSE81682 是否用于 CAdir 原文的来源覆盖，不签科学准入，也不涉及 counts、QC 或算法运行。

本轮可读到 PLOS 官方正文 Methods 的 “Experimental data”、Table 2 表题和 Tabula Muris cluster-number recovery 说明。正文列出多项已报告的分析数据；对正文全文检索 “Nestorowa” 和 “GSE81682” 均无匹配。这个结论的范围仅是主文：没有把正文未提及升级成“整篇文章未使用”。

PLOS 正文还明确链接 S1 Appendix，并说明附件含额外比较、分析和基准（HTML lines 485–493）。S1 DOI 点击因 HTTP 500 并转到当前浏览工具不可访问的 dx.plos.org 而未取得 PDF；PMC 页面给出 reCAPTCHA。PMC 搜索索引只显示附件名称、约 140.6 KB 文件大小及开头 S1 图的摘要，这不是文件访问收据。Table 2 图片也因签名存储地址不可访问而未核到各行内容。先前对作者固定 commit `c15b49578bde38b42fd5db2c9830c10dd441ee4c` 下 67 个源码/QMD 文件的审计结果已复用，没有重扫；其代码覆盖仍不能证明绝未使用。

因此，现有证据支持的表述是：**已检查的主文清单和固定作者仓库源码/QMD 中，没有发现 Nestorowa/GSE81682 被作为所报告评测数据列出或调用；官方 S1 和表格图像未覆盖。** 因 S1 本身涵盖额外分析，课程是否能在上述限定范围内接受该候选为“新数据”，需由独立科学评审明确决定。若评审认为不足，应继续保持 C04 阻塞；不得伪造关闭或切换数据集。
